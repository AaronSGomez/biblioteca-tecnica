El Concepto "Proxy Inteligente"

Seguridad (Spring Security)

La API que expones a Flutter debe estar protegida. Usa JWT o API Keys. Nadie debe poder invocar tu endpoint de "Enviar Factura" sin autorización.

Resiliencia (Resilience4j)

¿Si la AEAT está caída? Implementa un Circuit Breaker. Si falla, guarda la factura en tu BBDD con estado "Pendiente" y reintenta luego (Batch process).

¿Qué va dónde?

📂 aeat.generated

Aquí NO tocas código. Estas clases (miles de líneas) las crea Java automáticamente leyendo el WSDL de la AEAT. Definen la estructura exacta de la factura.

📄 AeatSoapClient.java

Aquí usas `WebServiceTemplate` (de Spring) o el cliente CXF. Cargas el objeto generado, inyectas el Header de seguridad y disparas.

🔑 certs/certificado.p12

Tu certificado digital. En Producción, esto NUNCA debe estar en el código fuente (Git). Se inyecta como un "Volume" de Docker o un "Secret" de Kubernetes.

Estrategia de Despliegue (Docker)

Al dockerizar la aplicación, eliminas el problema de "funciona en mi local pero no en el servidor". Además, la migración a la nube (AWS/Azure) es trivial: solo subes el contenedor.

# docker-compose.yml (Concepto)
services:
  verifactu-backend:
    image: verifactu-api:latest
    ports: "8080:8080"
    volumes:
      - ./certs:/app/certs # Inyección segura de certificados
    environment:
      - SPRING_PROFILES_ACTIVE=prod

  postgres-db:
    image: postgres:16
    volumes:
      - pgdata:/var/lib/postgresql/data

Plan de Mantenimiento

  • ✓ Logs Centralizados: Usa Logback configurado para rotar ficheros diariamente. Si algo falla, el log te dirá exactamente por qué la AEAT rechazó el envío.
  • ✓ Actualización Certificados: Los certificados caducan. Crea una alerta en tu calendario 1 mes antes. En Docker, solo cambias el archivo en la carpeta `certs` y reinicias.

Recuperación de Desastres

  • ⚠ Cola de Reintentos: Si la AEAT devuelve error 500, no pierdas la factura. Guárdala con estado `PENDIENTE_REENVIO` y ten un `@Scheduled` en Spring que reintente cada 10 mins.
  • ⚠ Backups DB: Configura un dump automático de PostgreSQL cada noche. Es tu única fuente de verdad.
